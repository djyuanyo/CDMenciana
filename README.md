# CD Menciana: datos deportivos públicos

Este repositorio contiene calendarios, resultados, actas y noticias procedentes de fuentes públicas del club y de RFAF, junto con los procesos que los actualizan.

No almacena fotos de perfil de usuarios, imágenes de avisos, cuentas, destinatarios, tokens ni credenciales. Las imágenes privadas se almacenan en el proyecto privado y se entregan mediante el servicio autenticado del club.

Los calendarios se consultan cada cinco minutos. Los avisos de resultados, horarios y noticias los procesa el servicio del club con sus credenciales privadas.
